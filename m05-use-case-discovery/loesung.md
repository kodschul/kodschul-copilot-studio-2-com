# M05 Lösung: Discovery-Canvas

## Erwartetes Ergebnis

### Canvas Use Case 1 — Datenextraktion aus Plänen → Solarcomputer

| Feld | Inhalt |
| --- | --- |
| Auslöser | Neuer Grundrissplan (PDF/DXF) liegt für ein Projekt vor |
| Heutiger Ablauf | Mitarbeitende lesen Flächen manuell aus dem Plan und tragen sie in Solarcomputer ein |
| Gewünschtes Ergebnis | Tabelle mit Raum/Bauteil, Fläche, Einheit automatisiert erzeugt und übernommen |
| Benötigte Systeme/Daten | PDF-/DXF-Plan, Copilot Studio, Power Automate, Solarcomputer |
| Risiken/offene Fragen | Kein bestätigter Solarcomputer-Connector; Planqualität schwankt |

### Canvas Use Case 2 — Aufmaßprüfung

| Feld | Inhalt |
| --- | --- |
| Auslöser | Massenaufstellung liegt vor, muss gegen Plan geprüft werden |
| Heutiger Ablauf | Manueller Zeile-für-Zeile-Abgleich Soll (Liste) gegen Ist (Plan) |
| Gewünschtes Ergebnis | Automatisch markierte Abweichungen (Ampel-Logik) |
| Benötigte Systeme/Daten | Massenaufstellung (CSV/Excel), Plan, Extraktions-Tool aus Use Case 1 |
| Risiken/offene Fragen | Nur Konzept-Skizze in dieser Schulung, kein fertiger Agent |

## Artefakte

- Zwei ausgefüllte Canvas-Blätter
