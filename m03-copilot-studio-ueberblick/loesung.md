# M03 Lösung: Agenten-Oberfläche erkunden

## Erwartetes Ergebnis

| Bereich       | Wofür (in eigenen Worten, Kernaussage)                                      |
| ------------- | --------------------------------------------------------------------------- |
| Instruktionen | Fester System-Prompt: Rolle, Sprache, Ausgabeformat des Agenten             |
| Wissen        | Wissensquellen (Dateien/SharePoint/Web), damit der Agent nicht halluziniert |
| Tools/Skills  | Konkrete Fähigkeiten, die der Agent bei Bedarf aufruft                      |
| Themen        | Klassische, feste Konversationsabläufe (in dieser Schulung nicht im Fokus)  |
| Testfenster   | Sofort ausprobieren, ob Instruktionen/Tools wie gewünscht funktionieren     |

Ohne Konfiguration antwortet der Agent im Testfenster meist generisch/allgemein — das zeigt, warum
Instruktionen und Tools nötig sind, um ihn auf die EFG-Use-Cases zuzuschneiden.

## Artefakte

- Notizzettel mit einem Satz pro Bereich
