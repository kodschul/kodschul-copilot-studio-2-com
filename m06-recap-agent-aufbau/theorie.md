# M06 Theorie: Recap & Aufbau eines einfachen Agenten

## Lernziel

Kernbegriffe aus Tag 1 aktiv wiedergeben, selbstständig einen einfachen Agenten in Copilot Studio
anlegen und konfigurieren können.

## Dauer

Tag 2 · 09:00–10:30 · 90 Minuten

## Recap-Quiz (Einstieg, 10 Min)

Per Handzeichen/Zuruf, siehe Leitfragen unten.

## Schritt-für-Schritt: neuen Agenten anlegen (30 Min, Live + Nachbauen)

1. In Copilot Studio "Neuer Agent" wählen
2. Name & Beschreibung vergeben (klar formulieren, wofür der Agent gedacht ist)
3. Instruktionen (System-Prompt) schreiben: Rolle, Sprache, gewünschtes Ausgabeformat festlegen (Bezug
   zu Prompt-Techniken aus M02)
4. Ein einfaches Tool hinzufügen und konfigurieren (Standard-Konnektor-Tool, keine EFG-Daten)
5. Im Testfenster ausprobieren, Instruktionen iterativ verbessern

→ Übung siehe [uebung.md](uebung.md).

## Leitfragen (Recap Tag 1)

<details>
<summary>Was ist der Unterschied zwischen Modell und Produkt (ChatGPT/Claude/Copilot)?</summary>

Modell = KI-Engine im Hintergrund, Produkt = Anwendung, in der man sie nutzt.

</details>

<details>
<summary>Was unterscheidet einen Agenten von einem Chatbot?</summary>

Ein Agent kann Tools aufrufen und handeln, ein Chatbot antwortet nur.

</details>

<details>
<summary>Was ist ein Skill/Tool?</summary>

Eine konkrete Fähigkeit, die der Agent bei Bedarf aufruft.

</details>

<details>
<summary>Nennt eine Prompt-Technik.</summary>

Kontext geben, Rolle zuweisen, Beispiele geben oder Schritt-für-Schritt.

</details>

<details>
<summary>Was "versteht", was "handelt" — Copilot Studio oder Power Automate?</summary>

Copilot Studio versteht, Power Automate handelt.

</details>
