# M06 Lösung: Agent von Grund auf aufbauen

## Erwartetes Ergebnis

Ein Agent mit:

- Name & Beschreibung (klar formuliert)
- Instruktionen, die Rolle, Sprache (Deutsch) und Ausgabeformat festlegen, z. B.:
  > "Du bist ein hilfreicher Assistent für [Thema]. Antworte immer auf Deutsch, kurz und in
  > Stichpunkten."
- Mindestens 1 konfiguriertes Tool
- Erfolgreicher Test im Testfenster mit mindestens 2 unterschiedlichen Anfragen

## Typische Stolperstellen (für den Trainer)

- Instruktionen zu vage formuliert → Agent antwortet inkonsistent (Lösung: konkreter formulieren,
  Beispiel-Ausgabe ergänzen)
- Tool-Beschreibung zu unklar → Agent ruft das Tool nicht zuverlässig auf (Lösung: Beschreibung
  präzisieren, siehe M03)

## Artefakte

- Funktionsfähiger Agent in der Trainingsumgebung
