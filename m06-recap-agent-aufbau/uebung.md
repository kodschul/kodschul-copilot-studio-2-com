# M06 Übung: Agent von Grund auf aufbauen

## Zeit

50 Minuten, einzeln oder zu zweit

## Ziel

Selbstständig einen einfachen Agenten in Copilot Studio anlegen, konfigurieren und im Testfenster
ausprobieren — als Grundlage für die Use-Case-Agenten an Tag 2 Nachmittag.

## Material

Zugang zu Copilot Studio (M365-Business-Konto)

## Vorgehen

1. Neuen Agenten anlegen, Name & kurze Beschreibung vergeben (z. B. "Test-Assistent für [eigenes Thema]").
2. Instruktionen schreiben: Rolle festlegen, Sprache (Deutsch) festlegen, gewünschtes Ausgabeformat
   beschreiben.
3. Ein Tool hinzufügen (ein vordefinierter Standard-Konnektor reicht, z. B. Websuche).
4. Im Testfenster mehrere Anfragen ausprobieren, Instruktionen bei Bedarf anpassen.
5. Optional: mit dem Sitznachbarn/der Sitznachbarin gegenseitig den Agenten testen und Feedback geben.

## Abnahme

- Ein funktionsfähiger, einfacher Agent mit mindestens 1 Tool ist vorhanden.
- Der Agent antwortet im Testfenster sinnvoll auf mindestens 2 unterschiedliche Anfragen.
